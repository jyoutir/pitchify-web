# pitchify-web

Marketing site, privacy policy, and support page for the [Pitchify](https://apps.apple.com/) iOS app.

Static HTML/CSS. Hosted via GitHub Pages.

## Pages

- `index.html` — landing / marketing page
- `privacy.html` — privacy policy (linked from App Store Connect)
- `support.html` — support page (linked from App Store Connect)

## Local preview

```sh
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy

Push to `main`. GitHub Pages serves from the branch root.
